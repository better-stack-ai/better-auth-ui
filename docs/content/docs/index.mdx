`@btst/better-auth-ui` 3.0 packages the React/shadcn components from Better Auth UI
1.7.26. It uses the matching upstream core and React packages for authentication,
queries, mutations, permission checks, and plugin configuration.

Register the BTST route families you need. Configure the corresponding upstream
UI plugins under `overrides.auth.plugins`; each application owns its Better Auth
server, client plugins, credentials, billing providers, and authorization policy.

- [Install and integrate with BTST](/installation)
- [Optional feature families](/features)
- [Migrate from version 2](/migration)
- [API and standalone components](/api)

The old fork-specific API reference has been replaced because upstream 1.7 changed
its provider, component, localization, and plugin APIs. The exact current behavior
and configuration are documented in [Better Auth UI's upstream documentation](https://better-auth-ui.com).
